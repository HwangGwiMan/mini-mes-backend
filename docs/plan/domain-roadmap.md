# MES 도메인 기능 로드맵

> 작성일: 2026-03-17

## 현재 구현된 도메인

| 도메인 | 설명 |
|---|---|
| commoncode | 공통 코드 (조회값) |
| employee | 담당자 |
| item | 품목 |
| partner | 거래처 |
| process | 공정 |
| quote | 견적 |
| salesorder | 수주 |
| shipment | 출하 |

---

## 핵심 누락 영역

### 1. 작업지시 (Work Order)

수주 → **작업지시** → 생산 실적으로 이어지는 생산 흐름의 핵심.

- 수주 라인 기반으로 작업지시 생성
- 지시 수량, 담당 공정, 예정일
- 상태 흐름: 대기 → 진행 → 완료 (`commoncode` 활용)

### 2. 생산 실적 (Production Result)

작업지시 대비 실제 생산량을 기록. 계획 대비 실적 비교의 기반 데이터.

- 작업지시 대비 생산량, 불량 수량
- 작업 시작 / 종료 시각
- 불량 사유 코드 (`commoncode` 활용)

### 3. BOM (Bill of Materials, 자재명세서)

품목을 생산하기 위해 필요한 자재와 수량을 정의.

- `item` 기반 부모-자식 구조
- 작업지시 생성 시 소요 자재 산출의 기반
- `item` 도메인 확장 또는 별도 도메인으로 분리

---

## 가치 있는 추가 영역

### 4. 재고 관리 (Inventory)

- 입고 / 출고 / 현재고 추적
- 출하(`shipment`) 시 재고 차감 연동
- 생산 실적 등록 시 자재 소모 반영

### 5. 구매 발주 (Purchase Order)

- 자재 부족 시 발주 생성
- `partner`(거래처) + `item` 활용
- 입고 확인 후 재고 반영

### 6. 품질 검사 (Quality Inspection)

- 입고 검사, 공정 검사, 출하 검사
- 합격 / 불합격, 불량 사유 코드 (`commoncode` 활용)

---

## 구현 우선순위

```
수주(기존) → 작업지시 → 생산실적 → 출하(기존)
                ↑
              BOM · 재고
```

| 우선순위 | 도메인 | 이유 |
|---|---|---|
| 1 | 작업지시 | 수주와 생산 실적을 잇는 핵심 연결고리 |
| 2 | 생산 실적 | 이것만 있어도 계획 대비 실적 조회 가능 — MES다운 시스템 완성 |
| 3 | BOM | 작업지시 생성 시 소요 자재 자동 산출에 필요 |
| 4 | 재고 관리 | BOM + 생산 실적이 갖춰진 후 연동 효과 극대화 |
| 5 | 구매 발주 | 재고 부족 알림과 함께 구성하면 효과적 |
| 6 | 품질 검사 | 재고·출하와 연동하여 완성도 높임 |
